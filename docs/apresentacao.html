Visão Geral do Sistema

Plataforma completa de gestão contábil para escritórios e clientes

O Presteza Contábil é uma plataforma digital que conecta escritórios de contabilidade aos seus clientes de forma eficiente e segura. Com interfaces dedicadas para cada perfil de acesso, o sistema centraliza processos, documentos, comunicação e relatórios em um único lugar — acessível pelo navegador ou como aplicativo instalado no celular.

Funcionalidades Principais

💬

Chat em Tempo Real

Comunicação direta entre escritório e clientes via WebSocket, com histórico completo de conversas.

📁

Gestão de Documentos

Upload com drag & drop, download e exclusão de documentos organizados por cliente.

📋

Kanban de Processos

Acompanhamento visual de processos contábeis com status Pendente, Em Andamento, Concluído e Cancelado.

👥

Gestão de Clientes

CRUD completo de clientes com busca, criação, edição e exclusão diretamente pelo painel admin.

🔔

Notificações em Tempo Real

Alertas automáticos para novas mensagens, documentos e atualizações de processos via WebSocket.

📱

App Mobile (PWA)

Instale o sistema na tela inicial do celular como um app nativo, com acesso offline a conteúdo cacheado.

🚀 Dois perfis de acesso, uma plataforma integrada

O sistema oferece interfaces distintas para o escritório (Admin) — com visão completa de todos os clientes, processos e documentos — e para o cliente — com acesso ao seu próprio portal, mensagens e acompanhamento de serviços. Ambos compartilham o mesmo banco de dados em tempo real.

Recursos Especiais

Tecnologias e funcionalidades que fazem a diferença

📱

PWA — App Instalável

O sistema funciona como um aplicativo nativo no Android e iOS. Após instalação via "Adicionar à tela inicial", o app abre instantaneamente, exibe uma tela de splash animada com o logo e funciona offline com conteúdo cacheado.

⚡

Comunicação em Tempo Real

Chat e notificações usam WebSocket (Socket.IO) para entrega instantânea de mensagens e alertas, sem necessidade de atualizar a página. A conexão é estabelecida automaticamente ao fazer login.

🌙

Modo Escuro

Alternância entre modo claro e escuro disponível em qualquer tela, com preferência salva automaticamente. Toda a interface — sidebar, topbar, cards e modais — adapta as cores sem recarregar a página.

🔔

Notificações Inteligentes

Sino de notificações no topo da tela com contador de não lidas. Clique em uma notificação para navegar diretamente para a tela relevante (chat, documentos ou processos). "Marcar todas como lidas" em um clique.

🖥️

Interface Responsiva

Sidebar colapsável no desktop, menu hambúrguer no mobile. Layout fluido que se adapta de 320px (celular pequeno) até monitores wide. Componentes acessíveis com áreas de toque mínimas de 44px.

🚀

Performance e SSR

Renderização híbrida Server-Side (SSR) + Client-Side. Primeira carga com HTML completo do servidor, navegação subsequente via SPA sem recarregar. Otimizado para conexões lentas e dispositivos de entrada.

Segurança & Conformidade

Proteção de dados e conformidade com a legislação brasileira

Mecanismos de Segurança

  • ✓
    Autenticação JWT (JSON Web Token)
    Tokens assinados com prazo de expiração. Cada requisição à API é validada pelo token, eliminando sessões persistentes no servidor. Armazenado de forma segura no localStorage do cliente.
  • ✓
    Controle de Acesso por Perfil (RBAC)
    Dois roles distintos: ADMIN (escritório) e CLIENT (cliente). Middleware de autenticação bloqueia acesso às rotas não autorizadas tanto no frontend quanto na API, com redirecionamento automático conforme o perfil.
  • ✓
    HTTPS em todas as conexões
    Frontend (Vercel) e API (Railway) servidos exclusivamente via HTTPS com certificados TLS automáticos. WebSocket também opera sobre WSS (WebSocket Secure).
  • ✓
    Senhas com hash bcrypt
    Nenhuma senha é armazenada em texto puro. O bcrypt aplica salt e hash antes de persistir no banco, tornando inviável a recuperação mesmo em caso de vazamento do banco de dados.

Conformidade com a LGPD

  • ✓
    Aviso de tratamento de dados na tela de login
    Texto informativo sobre o tratamento de dados pessoais para prestação dos serviços contábeis, com referência explícita à Lei nº 13.709/2018 (LGPD) e canal de contato para dúvidas.
  • ✓
    Dados pessoais acessíveis apenas pelo titular
    Cada cliente visualiza exclusivamente seus próprios documentos, processos e mensagens. O acesso cruzado entre clientes é bloqueado em nível de API.
  • ✓
    Banco de dados em infraestrutura certificada
    PostgreSQL hospedado no Neon com backups automáticos, criptografia em repouso e conformidade com padrões de segurança internacionais (SOC 2).
